## Parcours fonctionnel simplifié
1. moteur froid → thermostat fermé → petit circuit
2. moteur chauffe → thermostat s’ouvre → passage radiateur
3. si refroidissement insuffisant → thermocontact active ventilateur
4. calculateur adapte richesse via sonde température
