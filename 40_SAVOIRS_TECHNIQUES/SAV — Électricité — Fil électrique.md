## Valeurs caractéristiques

| Norme EU | Isolant PVC | °C max | °C min |
| -------- | ----------- | ------ | ------ |
| FLRYA    | Épais       | 105    | -40    |
| FLRYB    | Fin         | 105    | -40    |
| FLRYY    | Doublé      | 85     | -40    |

| Lettre | Signification                                                          |
| ------ | ---------------------------------------------------------------------- |
| FL     | Câble automobile                                                       |
| R      | Isolation à épaisseur réduite                                          |
| Y      | PVC souple (plastifié)                                                 |
| YW     | PVC souple (plastifié) résistant à la chaleur et à la pression à chaud |
| YK     | PVC souple (plastifié) résistant au froid                              |
| K      | Armure en fil de cuivre torsadé                                        |
| A      | Conducteur à structure symétrique conforme à la norme ISO 6722-1       |
| B      | Conducteur à structure asymétrique conforme à la norme ISO 6722-1      |
| 2X     | Polyéthylène réticulé (XLPE)                                           |
| 2G     | Caoutchouc silicone (SiR)                                              |
| 4G     | Éthylène-acétate de vinyle (EVA)                                       |
| 11Y    | Polyoléfine thermoplastique (TPE-O)                                    |
| 91Y    | Élastomère polyuréthane thermoplastique (TPE-U)                        |
